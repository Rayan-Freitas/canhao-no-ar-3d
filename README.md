# Canhão no Ar 3D

Jogo 3D no navegador: não tem chão. Você se mantém no ar soltando bolas de canhão embaixo de si e pulando nelas (combo Espaço, S, Espaço, S…). Derrube os outros com os tiros.

## Jogar

Abra o `index.html` no navegador, ou acesse a versão publicada no GitHub Pages.

## Controles

- **W A D**: mover · **Mouse**: mirar
- **Espaço**: pular (só encostado numa superfície)
- **S**: canhão embaixo (segure para carregar)
- **Q / E**: dash (atravessa tiros) · **N**: música liga/desliga
- **M**: trocar de modo (Clássico / Renascer) · **R**: reiniciar · **Esc**: pausa

## O que tem

- **Ritmo**: cada pulo na sua bola soma combo, e a música ganha camadas com ele.
- **Recarga perfeita**, **esquiva**, **pisão**, **defesa** e orbes de power-up.
- **Rodadas especiais** (gravidade lunar, ventania, bolas gigantes…) e **morte súbita** com o limite subindo.
- **Nível, XP, missões do dia** e visuais desbloqueáveis (rastros e chapéus). Os bots acompanham o seu nível.
