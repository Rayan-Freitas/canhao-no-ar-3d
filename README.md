# Canhão no Ar 3D

Jogo 3D no navegador: não tem chão. Você se mantém no ar soltando bolas de canhão embaixo de si e pulando nelas (combo Espaço, S, Espaço, S…). Derrube os outros com os tiros.

## Jogar

Abra o `index.html` no navegador, ou acesse a versão publicada no GitHub Pages.

## Controles

- **W A D**: mover · **Mouse**: mirar
- **Espaço**: pular (só encostado numa superfície)
- **S**: canhão embaixo (segure para carregar)
- **M**: trocar de modo (Clássico / Renascer) · **R**: reiniciar · **Esc**: pausa

## Publicar

Todo push na branch `main` atualiza o GitHub Pages sozinho.
